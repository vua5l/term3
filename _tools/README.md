# أدوات البناء

هذا المجلد خارج المواقع ولا يُنشر (اسمه يبدأ بشرطة سفلية).

- `common/`: الأدوات العامة لكل مادة جديدة. ابدأ بملف `common/README.md`.
- `<رمز المادة>/`: ما يخص مادة بعينها. للمادة الجديدة ملف إعداداتها `subject.json` وخطتها وحال دفعاتها `plan.json`.
- `law135/` و`law136/`: أدوات موقعين بُنيا قبل الأدوات العامة. تبقى كما هي، والإضافة إلى أحدهما تُبنى بأدواته.

لا يوضع نص الكتاب في هذا المستودع.
