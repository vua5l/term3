# تجارب طبقة «الطريق» في schedule.js

خمس تجارب تُشغَّل بـ node على بيانات المستودع، بحزام واحد `t.js`. ومواصفة الطريق في ملف المشروع `claude/الطريق.md`.

- T0: بلا طريق، ناتج `schedule.js` يطابق الأصل قبل الطريق حرفياً (10 حالات)، سوى فرق مقصود واحد منذ 25 نوفمبر: مهمة موقع إضافية لمادة رابعة لا تُلحق إن اكتملت مواد اليوم الثلاث.
- T1: اللصق، ومهام اليوم، والترحيل، والعلامات، والصفحات المعلّقة، وأيام الاختبارات، والموعد المخالف، والحفظ والمسح، ورفض الطريق المعيب.
- T2: سير يوم بيوم من 21 نوفمبر إلى 11 ديسمبر مع يومين فائتين. والتعلّم خارج الطريق مقبول فيها لدرس ينتهي قبل صفحة بداية مادته (كالفصلي الأول في الدولي ص 7–97).
- T4 (25 نوفمبر): لا يزيد يوم على ثلاث مواد (مهامه كلها ومنها الإضافية، مع صفحاته المعلّقة)، يوماً يوماً إلى آخر اختبار: بالدروس كما هي وبعد نشرها كلها، بطريق 21 نوفمبر وبالطريق المحفوظ في ملف المواعيد، بإنجاز كل يوم وبأيام فائتة.
- T5 (25 نوفمبر): قواعد قياس السرعة (السرعة بعينتين، والبطء بأربع، والاستراحة أكثر من ضعف التقدير، والحد الأدنى 0.25، والبداية من آخر نسبة)، وأن مهام اليوم الحقيقية لا تتغير إن أسرعتُ اليوم بل تصغر دقائقها. وتُقارن T0 منذ ذلك اليوم نسخةً أُعيدت فيها قواعد السرعة إلى ما كانت عليه (`schedule.t0.js` تكتبها T0 بنفسها).
- T3: الصفحة الحقيقية (`index.html` و`sync.js` و`app.js`) في متصفح محاكى (jsdom)، واللصق من زر «لصق الجواب» القائم. ومنذ 22 نوفمبر تفحص المرحلة الثانية أيضاً: رسالة «حُفظ الطريق» وسطر الخطة، ووسم «متأخر»، وسطر الصفحات المعلّقة، ونقاط التقويم يوماً يوماً، ونافذة اليوم (مطابقتها للرئيسية، وخانة التعلّم وحده في الأيام الآتية، والتعليم قبل اليوم والتراجع عنه، والإغلاق)، وبيان المادة الخارجة من الطريق، والمسح بضغطتين.

`path.json` هو ملف الطريق كما لُصق في 21 نوفمبر 2026.

## التشغيل
من جذر نسخة محلية فيها origin/main وorigin/progress (وorigin/temp-final-law114 إن بقي):

```
D=/tmp/pathtest; mkdir -p $D && (cd $D && npm init -y >/dev/null && npm i jsdom)
git show 49defdb:schedule.js > $D/schedule.orig.js            # الأصل قبل طبقة الطريق
cp schedule.js $D/schedule.js                                  # الملف الحالي (أو نسخة العمل بعد تعديلها)
cp _tools/schedule/path-tests/*.js _tools/schedule/path-tests/path.json $D/
for f in index.html sync.js app.js; do git show origin/main:$f > $D/$f; done   # أو نسخ العمل بعد تعديلها
for c in law114 law117 law135 law136 law138; do git show origin/main:$c/lessons.json > $D/$c.lessons.json; git show origin/progress:$c/_passes.json > $D/$c.passes.json; done
git show origin/progress:_schedule/exams.json > $D/exams.json
git show origin/temp-final-law114:law114/lessons.json > $D/law114temp.lessons.json   # إن بقي الفرع
cd $D && for t in t0 t1 t2 t3 t4 t5; do TZ=Asia/Riyadh node $t.js || break; done
```

- التجارب تبدأ بلا طريق مهما كان في ملف المواعيد، وتكمل ما لم يُنشر من الدروس بدروس وهمية (z1، z2…)، وساعتها مثبّتة. ويُصفَّر وقت حفظ ملف المواعيد (`savedAt`)، لأن الحفظ الحقيقي إن كان بعد ساعة التجربة غلب حفظها فرُفض اللصق.
- T3 تُشغَّل بتاريخ قبل آخر اختبار، فبعده لا يعمل الطريق أصلاً.
- T1 (د) تفترض بقاء دروس الدولي l1–l38 بصفحاتها.
- T3 تقبل وقتاً آخر: `node t3.js 2026-11-29T10:00:00+03:00`.
- إذا عُدّلت `schedule.js` تعديلاً مقصوداً يغيّر الناتج بلا طريق، فـ T0 تخفق حتماً: يُحدَّث سطر الأصل إلى آخر commit قبل التعديل.
